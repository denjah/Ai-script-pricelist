# Script Pricelist — Полный Архив Проекта (v2.0)

**Тип проекта:** Лендинг-прайс + интерактивный конфигуратор ИИ-услуг  
**Название:** ИИ-Помощники для бизнеса | Прейскурант 2026  
**Автор:** Денис Полоцк  
**Дата создания:** май 2026  
**Последнее обновление:** 08 мая 2026  
**Статус:** Завершён (production-ready)  
**Цель:** Создать премиальный, инженерный, продающий лендинг, который одновременно демонстрирует 13 готовых ИИ-решений и технический уровень Дениса.

## 1. Общая информация

**Главная задача**  
Быстро и красиво презентовать услуги, показать ценность (окупаемость 2–4 месяца), вызвать доверие и собрать лиды.

**Ключевые ценности дизайна**  
- Инженерный минимализм + тёплый бежево-бордовый вайб  
- Полноэкранные слайды (full-screen sections)  
- Максимальная интерактивность без перегрузки  
- Pixel-perfect responsive (от 1920px до 320px)  
- Высокая производительность (минимум зависимостей)

**Технический стек**  
- HTML5 + Tailwind CSS (CDN + custom config)  
- Vanilla JavaScript  
- Кастомный CSS (custom.css, configurator.css, hero-carousel.css)  
- Нет React / Next.js / shadcn (это чистая v1.1)

## 2. Что было сделано (ключевые этапы)

1. Архитектура — 9 full-screen слайдов  
2. Hero-секция + мощная hero-карусель  
3. Блок услуг с встроенными каруселями скриншотов  
4. **Гибридный конфигуратор цены** (Wizard + Presets + Manual mode)  
5. **ROI-калькулятор** в финальном блоке  
6. Анимированные цены (мультивалютный цикл + пульсация)  
7. Декорации (corner borders, background-figures, slide-header-bar)  
8. Полная адаптивность + оптимизация под мобильные  
9. Связка с `resume.html` + форма лида  
10. Магнитные эффекты, Ken Burns, scramble-анимации, reduced-motion

## 3. Ключевые промпты и системные инструкции

Основные правила проекта:
- `PROJECT_RULES.md` (v2.0) — 4-этапный процесс (подготовка → Figma → сборка → полировка)
- `follow-pricelist-rules.md` — жёсткая последовательность этапов
- `design-tokens.md` — все токены (цвета, типографика, spacing, corners)

## 4. Основные артефакты

**Главные файлы:**
- `index.html` — основной лендинг
- `configurator.js` + `configurator.css` — самый сложный конфигуратор
- `hero-carousel.js` + `hero-carousel.css`
- `resume.html` + `resume.js` — динамическое резюме с 4 профессиями
- `custom.css` — все кастомные стили и анимации

**Ключевые реализованные фичи:**
- Гибридный конфигуратор (wizard + manual + presets)
- Анимированные цены с циклом валют
- ROI-калькулятор с live-расчётом
- Hero-карусель со всеми услугами
- Карусели скриншотов внутри каждой услуги
- Магнитные CTA
- Background SVG-фигуры
- Scramble-анимация заголовков
