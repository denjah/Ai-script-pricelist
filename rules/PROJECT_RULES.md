## 2. Текущий Workflow (4 этапа) — СТРОГО СОБЛЮДАТЬ ПОСЛЕДОВАТЕЛЬНОСТЬ

### Этап 1. Подготовка макета к переносу в Figma
- Ручная реструктуризация текущего `index.html`
- Выделение логических блоков, улучшение семантики
- Подготовка CSS-переменных и структуры для удобного воссоздания в Figma
- **Не используем** дополнительные скиллы (кроме базового Tailwind, если уже начали миграцию)

### Этап 2. Ручная правка макета в Figma
- Перенос макета в Figma (`AI-Pomoshniki-2026-Design-v2`)
- Добавление фото, графики, иллюстраций
- Финализация hover-состояний, типографики, spacing
- Проработка всех 8 слайдов до pixel-perfect
- **Не используем** дополнительные скиллы — только ручная работа + Figma tools

### Этап 3. Обратная сборка макета в Antigravity из Figma
- Используем **Figma MCP** + чёткий промпт:
  ```
  Мы работаем над AI-Pomoshniki Portal v1.1 по правилам PROJECT_RULES.md v2.0.
  Полностью перестрой index.html из Figma файла [вставь ссылку].
  Сохрани структуру 8 full-screen слайдов, все цвета, типографику и spacing из токенов.
  Используй Tailwind CSS + семантические токены.
  После сборки проверь в Liveview.
  ```
- **Не подключаем** high-end-visual-design, ui-ux-designer и другие скиллы на этом этапе.

### Этап 4. Шлифовка, полировка и доведение до блеска (ТОЛЬКО ЗДЕСЬ ПОДКЛЮЧАЕМ СКИЛЛЫ)
- После успешной сборки из Figma переходим к этапу 4.
- Здесь подключаем скиллы из папки `skills/` проекта:
  - `tailwind-design-system/` — для создания чистых CVA-компонентов и улучшения структуры
  - `high-end-visual-design/` — для премиум-деталей (тени, micro-interactions, типографика, материалы)
  - `ui-ux-designer/` — для проработки форм, валидации, accessibility, interaction patterns
  - `product-design/` — только если нужно уточнить roadmap или приоритизацию фич

**Жёсткое правило:** Скиллы из `skills/` **запрещено** использовать на этапах 1–3. Они подключаются **только на этапе 4** и только после того, как прототип полностью собран из Figma.

## 3. Дизайн-система (строго обязательно)

1. **Всё начинается и заканчивается в Figma**
   - Файл: `AI-Pomoshniki-2026-Design-v2`
   - Страница токенов: `01 - Design Tokens`
   - Страница слайдов: `02 - Landing Slides 1920x1080`

2. **Токены — единственный источник правды**
   - Цвета, типографика, spacing, радиусы, тени — только из Figma.
   - Никогда не добавляем новые цвета/отступы "на лету" без обновления Figma.

3. **Workflow Figma → Code (Этап 3)**
   - После финализации в Figma — один большой промпт на полную пересборку.
   - После генерации — ручная проверка + мелкие правки только через токены.

## 5. Стандарты кода (обязательно к исполнению)

### Общие
- Семантический HTML5
- ARIA-атрибуты + полная клавиатурная навигация
- `loading="lazy"` + `decoding="async"` для изображений
- Никаких `!important`

### Tailwind + CSS (этап 3–4)
- Только семантические токены из Figma
- CVA для всех повторяющихся компонентов (ServiceCard, PriceBlock, FormField и т.д.)
- Responsive: desktop-first для full-screen слайдов + graceful мобильная версия

### Производительность
- Минимальный JS
- Критический CSS в head
- Избегать тяжёлых анимаций на мобильных
